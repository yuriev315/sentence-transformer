# sentence-transformer

[sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)
的模型文件（版本 `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`），由上游以 Apache-2.0 发布，许可证见 [`sentence_transformer_configs/LICENSE`](sentence_transformer_configs/LICENSE)。文件未作修改。

`model.safetensors`（470,641,600 字节）通过 Git LFS 存放，克隆前需安装 `git-lfs`。
